# Changelog

All notable changes to DiviOps Agent (the rubicon-maintained fork) are documented
here. The format is based on
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) and this project
adheres to [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html).

Entries are generated by release-please from Conventional Commits and curated

[oaris-dev/diviops](https://github.com/oaris-dev/diviops); versions before the
fork's own line began are upstream's.
